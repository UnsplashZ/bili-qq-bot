```javascript
async handleDisconnect(serverName, serverConfig) {
    // 检查配置文件，确认该服务是否仍启用
    try {
        const config = JSON.parse(fs.readFileSync(this.configPath, 'utf8'));
        const serverInConfig = config[serverName];

            return;
        }
```

### 5. 敏感信息处理建议

**问题**: `config/mcp_servers.json` 中 `env` 字段可能包含密钥，直接提交到版本库有风险

**建议方案**（不强制实施）:

方案A - .env 变量引用:
```json
{
  "server-name": {
    "command": "...",
    "env": {
      "${API_KEY}": true,
      "OTHER_VAR": "${OTHER_VAR}"
    }
  }
}
```

在 `mcpManager.js` 中解析:
```javascript
function resolveEnv(env) {
    const resolved = {};
    for (const [key, value] of Object.entries(env)) {
        if (typeof value === 'string' && value.startsWith('${') && value.endsWith('}')) {
            const envKey = value.slice(2, -1);
            resolved[key] = process.env[envKey] || '';
        } else {
            resolved[key] = value;
        }
    }
    return resolved;
}
```

方案B - 部署时注入:
- 在 `config/mcp_servers.json` 中使用占位符
- 部署脚本在启动前注入真实值
